## 22:05 - Discord認証キャンセル時のエラー画面を修正

**種別**: 修正
**対象ファイル**: `backend/app/routers/auth.py`, `frontend/src/pages/LoginPage.tsx`, `frontend/src/pages/LoginPage.test.tsx`

### 変更内容
- `discord_callback` エンドポイントの `code` パラメータをオプションに変更し、`error` パラメータを追加
- 認証キャンセル時（`error` あり / `code` なし）はフロントエンドの `/login?auth_error=cancelled` へリダイレクト
- `LoginPage` で `auth_error=cancelled` クエリパラメータを検知し「Discord 認証がキャンセルされました」メッセージを表示
- `LoginPage.test.tsx` に `MemoryRouter` ラップとキャンセルケースのテストを追加

### 理由
Discord OAuth 認証画面でキャンセルを押すと `code` なしでコールバックURLに戻るため、FastAPI が 422 エラーを返していた
