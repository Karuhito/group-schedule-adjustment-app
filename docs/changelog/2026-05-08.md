## 外部サービスのセットアップ・接続確認

**種別**: 設定 / 修正
**対象ファイル**: `backend/app/models/models.py`, `backend/alembic/versions/0001_initial_tables.py`

### 変更内容
- Supabase プロジェクトを作成し `backend/.env` に `DATABASE_URL` を設定（Session Pooler URL: `aws-1-ap-northeast-1.pooler.supabase.com:5432`）
- Discord Developer Portal でアプリを作成し `DISCORD_CLIENT_ID` / `DISCORD_CLIENT_SECRET` を `.env` に設定
- `JWT_SECRET`, `DISCORD_REDIRECT_URI`, `FRONTEND_URL`, `APP_ENV` を `.env` に設定
- `alembic upgrade head` で Supabase に初期テーブル（users, groups, group_members, schedules）を作成
- `backend/app/models/models.py`: 全 `DateTime` カラムを `DateTime(timezone=True)` に変更（TIMESTAMPTZ）
- `backend/alembic/versions/0001_initial_tables.py`: 同様に全 `DateTime()` を `DateTime(timezone=True)` に変更
- Discord OAuth フローの動作確認・Supabase の users テーブルへのユーザー登録を確認

### 理由
Supabase への INSERT 時に `asyncpg.exceptions.DataError: can't subtract offset-naive and offset-aware datetimes` エラーが発生。タイムゾーン付き datetime（`datetime.now(timezone.utc)`）をタイムゾーンなしの `TIMESTAMP` カラムに挿入しようとしていたため。`TIMESTAMP WITH TIME ZONE`（`DateTime(timezone=True)`）に統一して解決した。
