# 2026-07-02

## 12:00 - Supabaseスリープ防止ワークフローを追加

**種別**: 追加
**対象ファイル**: `.github/workflows/keep-db-alive.yml`, `docs/superpowers/specs/2026-07-02-supabase-keep-alive-design.md`

### 変更内容
- GitHub Actionsのスケジュール実行で3日に1回、`psql "$DATABASE_URL" -c 'SELECT 1;'` を実行するワークフローを追加
- cronは `0 3 */3 * *`（毎月1,4,7,...,28,31日 UTC 3:00 / JST 12:00）
- `workflow_dispatch` を付与し手動実行での動作確認を可能にした
- 設計ドキュメントを追加

### 理由
- Supabase無料プランは7日間DBへアクセスがないと一時停止するため、定期的にDBへ触ってスリープを防ぐ
- scheduleは失敗しても前倒しされないため、1回失敗しても7日以内に次回が来るよう3日間隔にした
