## 15:00 - FastAPI メインアプリ追加、テスト修正

**種別**: 追加 / 修正
**対象ファイル**: `backend/app/main.py`, `backend/app/routers/auth.py`, `backend/tests/test_auth.py`

### 変更内容
- `backend/app/main.py` を新規作成（FastAPI アプリ本体、CORS ミドルウェア、ルーター登録、/health エンドポイント）
- `backend/app/routers/auth.py`: `RedirectResponse` に `status_code=302` を明示（デフォルトは 307 のため）
- `backend/tests/test_auth.py`: `httpx.Response.json()` は同期メソッドのため、モックを `AsyncMock` から `MagicMock` に変更

### 理由
`main.py` は全テストの `client` フィクスチャが `from app.main import app` でインポートするため必須。
`RedirectResponse` のデフォルトステータスコードが 307 であるため、仕様（302）に合わせて明示する必要があった。
