## 21:36 - datetime.utcnow 非推奨対応

**種別**: 修正
**対象ファイル**: `backend/app/models/models.py`, `backend/tests/test_models.py`

### 変更内容
- `models.py` の各モデルの `created_at` デフォルト値を `default=datetime.utcnow` から `default=lambda: datetime.now(timezone.utc)` に変更
- `test_models.py` の対応箇所も同様に修正

### 理由
Python 3.12 で `datetime.utcnow()` が非推奨となった。`timezone.utc` を明示してタイムゾーン付き UTC を返すように修正した。
