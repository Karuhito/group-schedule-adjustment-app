## 11:00 - weeklyGridUtils（週次グリッド変換ユーティリティ）を実装

**種別**: 追加
**対象ファイル**: `frontend/src/components/schedule/weeklyGridUtils.ts`, `frontend/src/components/schedule/weeklyGridUtils.test.ts`, `frontend/vite.config.ts`

### 変更内容
- `weeklyGridUtils.ts` を新規作成し、週次グリッドUIで使う変換ユーティリティ関数を実装
  - `getWeekDates`: 月曜起点で7日分のDateを返す
  - `isPastDate`: 今日より前の日付かどうかを判定する
  - `getTimeSlots`: 30分刻み48スロットの時刻文字列を返す
  - `keySetToSlots`: "YYYY-MM-DD HH:mm" キー集合を連続マージしてScheduleSlot[]に変換する
  - `slotsToKeySet`: ScheduleSlot[]を30分単位のキー集合に展開する
  - `partitionSlotsByWeek`: スロットを当週内・当週外に分類する
- `weeklyGridUtils.test.ts` を新規作成し、全関数のユニットテスト（14件）を実装（TDD）
- `vite.config.ts` に `/// <reference types="vitest" />` と `env: { TZ: 'Asia/Tokyo' }` を追加（CI環境との差異防止）
